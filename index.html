How the score works

The score goes from 0 to 100. Below 25 is calm, 25 to 59 is unusual activity, and 60 or more is behaviour that looks like ransomware.

  • Burst of changes. Up to 40 points when the number of changes in the burst window reaches your threshold. A burst alone never reaches the alert level, because backups, installs and builds do the same thing.
  • Random-looking contents. 25 points per file whose first 16 KB went from ordinary data to near-random data, which is what encryption produces. Zip, Office, image, audio and video files are skipped because they always look random.
  • Ransomware-style extensions. 30 points per file created or renamed to something like .locked or .lockbit.
  • Appended extensions. 20 points per file renamed from report.docx to report.docx.something.
  • Ransom note. 40 points when a file named like HOW_TO_DECRYPT_FILES.txt appears.
  • Deletions. 4 points per deleted file, up to 20.

Strong signals count for 60 seconds. When the score reaches the alert level, a banner stays on screen until you dismiss it.

What this can and can't do

It warns you. It can't stop, block or undo anything, so keep real backups and use proper antivirus alongside it.

It only sees the folder you choose, and only while this tab is open. Chrome asks for permission each time, and your files are never uploaded: everything is analysed in this tab. Mobile browsers generally do not allow web pages to continuously monitor folders, so on a phone you can use the demo but not live folder monitoring.

It can miss ransomware that encrypts slowly, or that encrypts files which already look random. It can raise false alarms during large legitimate jobs.
